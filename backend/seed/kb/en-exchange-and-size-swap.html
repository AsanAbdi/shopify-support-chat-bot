Exchange for another size or colour

You can exchange an item for another size or colour of the same product within 30 days, free of charge. Choose Exchange in the returns portal and select the new size.

  • We send the new item as soon as the carrier has scanned your return parcel.
  • If the new size or colour is out of stock, we refund the item instead.
  • For a different product, place a new order and return the first one for a refund.

The size guide helps you choose: our running shoes run half a size small, boots fit true to size.
